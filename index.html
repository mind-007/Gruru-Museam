The 5-Stage Knowledge Pipeline

โครงเรื่องมาตรฐานและกระบวนการทำงานของทุกนิทรรศการ (Excavate → Decode → Retell → Connect → Apply)

01
EXCAVATE
[ขุดค้นและคัดสรร]

ค้นคว้าจากจดหมายเหตุ ประวัติศาสตร์ วิทยาศาสตร์ และภูมิปัญญาโบราณ ระบุแหล่งอ้างอิงชัดเจนทุกชิ้น

02
DECODE
[ถอดรหัสโครงสร้าง]

แปลงข้อมูลดิบให้เป็นโหนด (Nodes) และเส้นโยงความสัมพันธ์ (Relations) ใน Knowledge Graph

03
RETELL
[เล่าเรื่องผ่านภาพ]

Visual Storytelling สไตล์ Modern Art นำเสนอด้วยภาพ กราฟิก และแอนิเมชันที่ดูจบในไม่กี่นาที

04
CONNECT
[เชื่อมโยงเครือข่าย]

เปิดชุดข้อมูลผ่าน Data Booming และ Interactive Graph ให้ผู้ใช้เห็นการเชื่อมต่อข้ามศตวรรษ

05
APPLY
[นำไปใช้ในชีวิตจริง]

สรุปเป็นการ์ด Everyday Takeaway เผยวิธีปรับใช้กับสุขภาพ การงาน หรือการตัดสินใจประจำวัน

GRM-2026-ENG-006 // DUAL GRAPH ARCHITECTURE
⚡ 2 โมเดลผลิตภัณฑ์: Data Booming (นำทางแบบระเบิดความคิด) & Interactive Graph (แผนที่สำรวจเสรี)

นวัตกรรม Knowledge Graph 2 รูปแบบ

MODE A // GUIDED DISCOVERY Signature Innovation

1. DATA BOOMING (ระเบิดความคิด)

ประสบการณ์แบบนำทาง ผู้ใช้เริ่มจากหัวข้อเดี่ยวใจกลางจอ แล้วระเบิดออกเป็นความรู้ที่เชื่อมโยงกันทีละชั้น

[SPECIFICATION SPECS]
  • ระเบิดออก 6–12 โหนดลูก เรียงเป็นวงรัศมี
  • Staggered entrance: โหนดโผล่ห่างกัน 40ms
  • รัศมีวงแหวน Lime เรืองแสงพร้อมตัวนับความเชื่อมโยง
  • กดระเบิดเจาะลึกได้สูงสุด 3 ชั้น แล้วส่งต่อไปยัง Graph เต็ม
MODE B // FULL EXPLORATORY MAP Deep Research

2. INTERACTIVE GRAPH (แผนที่สมบูรณ์)

แผนที่ความรู้ฉบับเต็ม ให้ผู้ใช้สำรวจ กรองตามหมวด เลื่อนไทม์ไลน์ประวัติศาสตร์ และเจาะลึกได้เอง

[ENGINEERING SPECS]
  • สร้างด้วย D3.js (d3-force) เรนเดอร์บน HTML5 Canvas
  • ขนาดโหนด 8–32px ปรับตามจำนวน Inbound Links
  • เส้นสัมพันธ์ 3 แบบ: Influenced (ทึบ), Derived (ประ), Used (จุด)
  • Hover เผย Specimen Label พร้อมมินิแมปและไทม์ไลน์สไลเดอร์
